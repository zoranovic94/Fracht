# Fracht-Wächter mobil

Handy-Ansicht für die Meldungen des Fracht-Wächters (MZ Transport). Die Seite liest die ntfy-Kanäle direkt im Browser; der Kanalname wird nur auf dem Gerät gespeichert und steht nicht in diesem Repository.

## Töne

- `toene/lkw-signal.mp3`: „Truck Signal“ von audiopapkin, Pixabay (Pixabay-Inhaltslizenz)
- `toene/hinweis.mp3`: „Correct 2“ von freesound_community, Pixabay (Pixabay-Inhaltslizenz)
- übrige Dateien in `toene/`: für diese App erzeugt
